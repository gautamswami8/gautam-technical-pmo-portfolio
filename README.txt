GAUTAM SWAMI — TECHNICAL PMO PORTFOLIO
======================================

Included:
- index.html: complete responsive, animated static website.
- No backend or paid software is required to preview it.

BEFORE PUBLISHING
1. Open index.html in a browser and review every section.
2. Find YOUR.EMAIL@example.com and replace it with your preferred professional email.
3. Replace https://www.linkedin.com/ with your actual LinkedIn profile URL.
4. Verify the wording of your skills and experience. SQL, Power BI, Power Query and DAX are marked as learning/developing where appropriate; adjust only if accurate.
5. The projects labelled “Practice project · Build next” are project concepts, not completed projects. Build them with synthetic/public data before presenting results.
6. Never publish confidential employer/client data, internal dashboards, tickets, screenshots, or documents.

FREE HOSTING WITH VERCEL
1. Create/sign in at https://github.com/
2. Create a repository such as gautam-technical-pmo-portfolio.
3. Upload index.html to the root of the repository.
4. Sign in at https://vercel.com/ and import the GitHub repository.
5. Use default settings and select Deploy.
6. Vercel will provide a public URL. A custom domain is optional.

ALTERNATIVE: GITHUB PAGES
Create a repository, upload index.html, then open Settings > Pages and publish from the main branch/root folder.

Website features: responsive layout, mobile navigation, animated hero illustration, scroll reveal effects, project filters, reduced-motion support.
Fonts are loaded from Google Fonts; the rest is a static site.
